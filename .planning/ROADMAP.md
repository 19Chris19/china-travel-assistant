# Roadmap

## v0.2.0 - OmniRoute Skill Engine

- Standard, Pro, and Pro Max exploration tiers with Auto biased toward Pro.
- Deterministic multimodal route composition, evidence scoring, and risk disclosure.
- Visualize-first presentation with exact local HTML, SVG, and Markdown fallbacks.
- Eight visible Agent Skills and complete provider setup documentation.

## v0.3.0 - Multisource Facts (Released)

- Generic gateway discovery and ranking without city-specific airport rules.
- Place evidence, optional QWeather outdoor risk, and a narrow provider-health ribbon.
- Public brand 远行计划局 with Chinese route-tier labels and compatible canonical API values.
- macOS Keychain-backed credential profiles, optional provider installation, strict Skill routing boundaries, and reproducible release assets.

## v0.4.0 - Product-Owned UI (Proposed)

- Evaluate an MCP-backed App UI through the Apps SDK before committing to implementation.
- Keep the validated itinerary JSON as the single fact source for an editable board.
- Consider decorative ImageGen backgrounds that never contain authoritative itinerary facts.

## v2 - Housing

- Original China rental adapters and contracts, isolated from the MIT travel core until licensing and provider access are verified.
